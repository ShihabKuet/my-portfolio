## [1.0.5] - 2026-06-18

### Added
- **Responsive Table of Contents for project pages** — on screens narrower than `lg` (< 1024 px) a fixed floating capsule button appears at the bottom of the viewport showing the current active section. Tapping it opens a slide-up bottom sheet with the full TOC list; tapping a link or the backdrop closes it. Body scroll is locked while the sheet is open.
- **Table of Contents for blog posts** — both the desktop sticky sidebar (lg+) and the mobile floating capsule / bottom sheet are now available on every blog post page, reusing `TableOfContents`, `TableOfContentsMobile`, and `extractTOC` from the projects module. The blog post layout was widened from `max-w-3xl` to `max-w-5xl` to accommodate the sidebar while keeping the header and footer constrained to reading width.

## [1.0.1] - 2026-04-28

### Added
- Individual project deep-dive pages (`/projects/[slug]`) rendered from MDX case studies with hero image, status badge, tag chips, tech stack pills, GitHub / Live / Marketplace CTAs, and a sticky Table of Contents sidebar.
- Project listing page (`/projects`) with card grid, keyword search, and category / tag filter.
- Floating terminal widget — draggable overlay with spring animations, maximize / minimize toggle, and an extended command set (`neofetch`, `help`, `history`, `open`, `uname`, `date`, `echo`, `man`).
- OSI / TCP-IP interactive scroll-driven encapsulation page (`/osi`).
- Custom 404 page with a segfault animation and mock recovery terminal prompt.
- Blog fun-fact random banner on the listing page.
- LeetCode coding stats section with a live proxy API route and animated count-up counters.
- Tech Expertise section with animated custom SVG icons and a category filter.
- Achievements & Certifications section with FE Exam highlight.
- Scroll progress bar, back-to-top button, and active-section highlight in the navbar.
- `sitemap.ts` and `robots.ts` auto-generated by Next.js for SEO.
- Per-page Open Graph tags, canonical URLs, and social sharing metadata.
- Google Search Console and Bing webmaster verification meta tags.
- Blog live search bar (`⌘K`) with `AnimatePresence` card transitions.
- Touch-event parity on blog cards (`onTouchStart` / `onTouchEnd` mirrors hover state).
- Co-located interactive components inside blog MDX posts (`NicRoutingDemo`, `Utf8deepdive`).
- Resume PDF download button in the hero section.
- ResearchGate, Medium, and blog links added to hero social icons.

### Changed
- Hero section redesigned to a side-by-side layout — bio / CTAs left, live terminal right.
- Hero terminal upgraded with authentic C networking code and extended command vocabulary.
- Work Experience section redesigned with a network-topology visual style.
- Skills section updated with hexagonal badge grid and 3D glossy star ratings.
- Navbar changed to an icon-based layout with tooltip labels.
- Blog listing redesigned to book-style cards with coloured spines, cover image gradient mask, and excerpt slide-up on hover.
- Contact section merged the SMTP data-packet animation with the submission form.

### Fixed
- Switched from `next-mdx-remote` to `next-mdx-remote/rsc` for correct App Router static generation.
- Scroll position reset prevented on client-side route changes.
- Blog code block syntax highlighting (highlight.js theme import order).
- Section counter offset causing incorrect active-nav highlighting.

## [1.0.0] - 2026-04-01

Initial public release.

### Added
- **Next.js 16 App Router** project scaffolded with React 19, TypeScript, and Tailwind CSS v4.
- **Navbar** — icon-based navigation with animated logo, tooltip labels, and dark/light mode toggle.
- **Hero section** — character-scramble name decode animation, alternating slide-in sub-headlines, word-by-word blur-reveal bio paragraph, and social icon links.
- **About section** — animated quote box, profile photo, and personal-stat pills.
- **Skills section** — hexagonal badge grid.
- **Education section** — endian-style animated timeline.
- **Experience section** — work history cards.
- **Projects section** — featured project cards with demo links and tech tags on the home page.
- **Publications section** — academic paper cards.
- **Contact form** — wired to a `/api/contact` route using the Resend SDK.
- **Footer** with social links.
- **MDX blog** — listing page and individual post routes (`/blog/[slug]`) using `next-mdx-remote/rsc`; syntax highlighting via `rehype-highlight`, GFM tables via `remark-gfm`, and heading anchors via `rehype-slug`.
- **Dark / light mode** — zinc-950 dark theme · sky-50 light theme; no hardcoded colour values.
- Global `ScrollProgress` bar and `BackToTop` button.
- Favicon, `apple-icon`, and OG image assets.
